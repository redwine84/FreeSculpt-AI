# FreeSculpt-AI

A modern open-source Android app for 3D sculpting, mesh design, animation, and AI-assisted creative workflows.

This project is intentionally developed from first principles as an original codebase to avoid legal and IP ambiguity. It is not a fork or clone of any proprietary sculpting application.

## Features
- 3D viewport foundation
- Sculpting tool architecture
- Animation-ready scene graph
- AI agent integration layer
- Clean Material 3 interface
- Open format export/import approach

## Tech stack
- Kotlin
- Jetpack Compose
- Android SDK / NDK
- OpenGL ES / Vulkan-ready renderer architecture
- Local AI integration via HTTP/WebSocket connectors

## Getting started
```bash
git clone https://github.com/redwine84/FreeSculpt-AI.git
cd FreeSculpt-AI
./gradlew assembleDebug
```
